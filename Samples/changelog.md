# Changelog

All notable changes to MDLook are recorded here.

## 0.4.0 - Image Experience

### Added

- Local image figures with captions.
- Remote image placeholders when network images are disabled.
- Link classes for [external](https://example.com), [local](regression.md), and <mailto:support@example.com> links.

### Changed

- Task list items keep the checkbox and text on one line.
- Code blocks show language labels for `swift`, `json`, `yaml`, `bash`, and `mermaid`.

## 0.3.0 - Renderer Compatibility

| --- | --- |
| ~~Raw HTML~~ | removed |
| ==Highlight== | rendered as mark |
| Footnotes[^compat] | supported |
